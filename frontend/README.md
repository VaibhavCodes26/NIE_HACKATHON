# NammaPrayana — frontend (Phase 1)
React + Vite. Run from this folder (Windows PowerShell):

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build -> dist/

Data lives in `src/data/` (destinations, categories/dishes, translations, Karnataka outline).
Photos are hot-linked from Wikimedia Commons; set `file: null` or add a Commons filename in the data files to change them.
